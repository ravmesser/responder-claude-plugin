# איך יוצרים דף נחיתה בעזרת ה-MCP של רב מסר?

Category: רב מסר ומערכות חיצוניות

ה-MCP של רב מסר מאפשר ליצור דף נחיתה מלא בשיחה פשוטה עם ה-AI מבלי לפתוח את העורך ובלי ידע בעיצוב. 

כל מה שצריך לעשות זה לתאר במילים מה רוצים, וה-AI יבנה לכם את הדף דרך ה-MCP, יחבר את טופס ההרשמה לרשימת התפוצה, ישלב תמונות מהגלריה ברב מסר ויפרסם את הדף בכתובת שבחרתם. 

כך עוברים במהירות מרעיון לדף חי, וממשיכים לשפר אותו באותה שיחה.



## איך יוצרים דף נחיתה דרך ה-MCP?


### 1. מתארים את מטרת הדף

ככל שהבקשה תהיה מפורטת יותר, יהיה ל-AI קל יותר להכין דף שמתאים לצרכים שלכם. 

ציינו:

- מה אתם מציעים ולמי.
- איזו פעולה תרצו שהמבקרים יבצעו.
- אילו חלקים יופיעו בדף.
- מהם הצבעים והסגנון הרצויים.
- אילו פרטים צריך לאסוף בטופס.
- לאיזו רשימת תפוצה יתווספו הנרשמים.

**לדוגמה:**

צור דף נחיתה בעברית להרשמה לסדנת צילום למתחילים. כלול כותרת ראשית, הסבר על הסדנה, שלושה יתרונות, פרטים על המרצה וטופס הרשמה עם שם וכתובת דוא״ל. השתמש בצבעי כחול ולבן והתאם את הדף גם לטלפון נייד.

### 2. מחברים את טופס ההרשמה לרשימה

כדי שהפרטים יישמרו ברב מסר, צריך לחבר את הטופס לרשימת תפוצה. אפשר להשתמש ברשימה קיימת או לבקש ליצור חדשה.

**לדוגמה:**

חבר את טופס ההרשמה לרשימה ״נרשמים לסדנת צילום״. לאחר ההרשמה העבר את המבקרים לדף התודה שלי.

**חשוב:** הטופס צריך להיות מפורסם כדי שיוכל לפעול בתוך הדף. כפתור או טופס שמופיעים בעיצוב בלבד אינם מספיקים לקליטת נרשמים.
### 3. משלבים תמונות מהגלריה

את התמונות שרוצים לשלב בדף יש להעלות תחילה לגלריית התמונות ברב מסר. לאחר ההעלאה, ה-MCP יכול לטעון אותן מהגלריה ולשלב אותן בדף.

מומלץ לתת לתמונות שמות ברורים, כדי שיהיה קל לזהות את הלוגו, תמונת המרצה או תמונת הרקע המתאימה.

סדר העבודה הוא:

1. העלו את התמונות לגלריה ברב מסר.
2. ציינו ל-AI באילו תמונות להשתמש.
3. הסבירו היכן למקם כל תמונה.

**לדוגמה:**

העליתי לגלריה לוגו בשם ״לוגו העסק״ ותמונה בשם ״סדנת צילום״. שלב את הלוגו בראש הדף ואת תמונת הסדנה ליד הכותרת הראשית.

**שימו לב:** צירוף תמונה לשיחה אינו מחליף את העלאתה לגלריה ברב מסר.
### 4. בודקים ומבקשים שינויים

לאחר יצירת הטיוטה, בדקו את הטקסט, העיצוב, התמונות וטופס ההרשמה. אפשר להמשיך לבקש שינויים באותה שיחה:

קצר את הכותרת הראשית, הגדל את כפתור ההרשמה והעבר את פרטי המרצה לפני הטופס.

מומלץ לבדוק את הדף גם במחשב וגם בטלפון נייד, ולבצע הרשמת ניסיון כדי לוודא שהפרטים מגיעים לרשימה הנכונה. ### 5. מפרסמים את הדף

יצירת הדף שומרת אותו כטיוטה. כדי שיהיה נגיש למבקרים, יש לבקש לפרסם אותו.

**לדוגמה:**

הצג לי את כתובות הפרסום הזמינות בחשבון, ולאחר שאבחר כתובת פרסם בה את הדף ושלח לי את הקישור.

לאחר הפרסום, פתחו את הקישור ובדקו שהדף וטופס ההרשמה פועלים כמצופה.

## איך ממשיכים לערוך דף קיים?

אפשר לבקש שינויים בדף שנוצר דרך ה-MCP, למשל החלפת כותרת, עדכון צבעים או שילוב תמונה אחרת מהגלריה.

כדאי להמשיך באותה שיחה ולציין במפורש לאיזה דף מתייחסים.

אם ערכתם את הדף גם בעורך של רב מסר, עדכנו את ה-AI לפני בקשת שינוי נוספת: שינויים שבוצעו ישירות בעורך אינם בהכרח זמינים לו לקריאה. **זקוקים לעזרה?**
נתקלתם בקושי טכני? זקוקים לסיוע בהגדרת החיבור או בשאלות על תפעול המערכת? צוות התמיכה שלנו עומד לרשותכם.
