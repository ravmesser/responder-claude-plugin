# מסך הגדרת חיבורים חיצוניים (api)

Category: הגדרות החשבון שלך

מסך **חיבורים חיצוניים (API)** במערכת רב מסר מאפשר לכם לחבר את החשבון שלכם למגוון מערכות ופלטפורמות מובילות – ללא צורך בכתיבת קוד או בפיתוח מורכב.

החיבור המובנה (אינטגרציה) מאפשר לרב מסר ולמערכות חיצוניות לתקשר זו עם זו בצורה מאובטחת, להעביר נתונים בזמן אמת (כמו הוספת לידים או סנכרון לקוחות מ-CRM) ולחסוך עבודה ידנית כפולה.

1. התחברו לחשבון שלכם ברב מסר.
2. לחצו על **סמל גלגל השיניים (הגדרות)** בפינה השמאלית העליונה של המסך.
3. בחרו בלשונית **"חיבורים חיצוניים (API)"**.

מיד מתחת למפתח הכללי של החשבון נוכל למצוא רשימה של כל המערכות שפיתחו אינטגרציה ישירה לרב מסר, כמו גם מספר מערכות ותוספים שאנחנו יצרנו.

כדי למצוא ולהפעיל את החיבור המבוקש בקלות, עומדים לרשותכם כלי חיפוש וסינון מתקדמים:


- **איתור מהיר של מערכת:**
  - **שדה חיפוש:** הקלידו את שם המערכת בשורת הניווט (`חיפוש...`).
  - **סינון לפי קטגוריות:** לחצו על התגית המתאימה כדי לסנן את הרשימה לפי תחום העיסוק – *CRM, אוטומציות, סליקה, אתרים ודפי נחיתה, וובינרים* ועוד.
  - **סינון לפי סטטוס:** לחצו על הכפתור **"פעילים בלבד"** כדי לצפות במהירות רק בחיבורים שמוגדרים כרגע בחשבון שלכם.
- **הפעלת החיבור והעתקת נתונים:**
  1. העבירו את ה**מתג** שלצד שם המערכת למצב **פעיל**.
  2. העתיקו את אסימון הגישה או הקוד הייעודי באמצעות **סמליל ההעתקה** (אייקון הדפים) והזינו אותו במערכת השנייה. לצפייה בפרטים המוצפנים תוכלו ללחוץ על **סמליל העין**.

אם המערכת שברצונכם לחבר אינה מופיעה ברשימת האינטגרציות המובנות, עומדות לרשותכם שתי חלופות מתקדמות:

- **פיתוח ייעודי מאפס לשימושכם האישי:**אם אתם רוצים לבנות אינטגרציה מותאמת אישית בקוד, תוכלו להשתמש במפתח הכללי לחשבון ובממשק ה-API המתקדם שלנו. לתיעוד המלא ולתהליך ההתממשקות עברו למדריך: חיבור רב מסר למערכות חיצוניות באמצעות API V2.0.
- **רוצים לנהל את החשבון בעזרת AI ללא כתיבת קוד?**תוכלו לחבר את כלי ה-AI שלכם (כמו Claude או ChatGPT) ישירות לחשבון באמצעות שרת ה-MCP שלנו, ולבצע פעולות, לפלח רשימות ולנהל אוטומציות בשיחה פשוטה בשפה טבעית. לפרטים מלאים עברו למדריך: חיבור מערכות AI ל-MCP של רב מסר - לנהל את מערכת הדיוור שלכם בשיחה פשוטה עם AI.
- **מפתחים מערכת שתרצו להציע כאינטגרציה מובנית לכלל משתמשי רב מסר?**
צרו קשר עם צוות התמיכה שלנו ונשמח לסייע ולכוון אתכם בתהליך.
