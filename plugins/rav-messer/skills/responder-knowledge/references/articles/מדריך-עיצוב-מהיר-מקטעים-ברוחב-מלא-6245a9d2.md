# מדריך עיצוב מהיר: מקטעים ברוחב מלא

Category: הגדרות החשבון שלך

סדרת המדריכים המהירים שלנו לעיצוב תוכן נועדו לחסוך לכם את זמן הלימוד, הניסוי והטעייה בדרך ליצירת תוכן בעיצוב אלגנטי, יעיל ומושך. התוכן עצמו הוא כמובן באחריותכם, אבל כדי להגיע לעיצוב מעניין תוכלו לעקוב אחרי ההנחיות המהירות כאן, וכמובן תוכלו לשנות וליצור וריאציות משלכם.

ההנחיות כאן הן בניסוח מקוצר, ולא מפורטות צעד אחרי צעד, בהנחה שאתם כבר יודעים איך לעבוד עם העורך שלנו. אם אתם צריכים הסברים כלליים על העבודה עם העורך, תמצאו אותם כאן.

מה זה 'מקטעים ברוחב מלא'

לפעמים רוצים שהתוכן, או חלק ממנו, יתפוס את מלוא רוחב המסך ללא שוליים - כלומר ממש יגע בגבולות התצוגה האפשריים מימין ומשמאל.

נציג כאן שלוש וריאציות של העיצוב הזה.

באופן כללי:

אפשר להפוך את כל המקטעים בעמוד לרוחב מלא על ידי 'דף / עיצוב / רוחב'

אפשר גם להפוך חלק מהמקטעים לרוחב מלא על ידי 'מקטע / עיצוב / גודל / רוחב פנימי = רוחב מלא'

שלוש תמונות בפרישה לכל רוחב המסך

כדי ליצור עיצוב כזה מגדירים כך:

טבלה / עריכה / 'כמות עמודות' = 3

טבלה / עריכה / סוג עמודות = 'עמודות ברוחב מלא, קבועות במחשב ובנייד' (כדי שבנייד התמונות עדין יהיו אחת לצד השנייה)

טבלה / עיצוב / שוליים / שוליים פנימיים = 0 מימין ומשמאל (כדי שהטבלה תגיע לקצה של המסך)

טבלה / עיצוב / שוליים / מרחק בין עמודות = 0 (כדי שהתמונות יגעו אחת בשנייה)

תמונה / עריכה / רוחב = רוחב מלא (כדי שכל תמונה תתפוס את הרוחב המלא של התא שבתוכה היא נמצאת, במקרה שלנו זה מוביל לשליש מרוחב המסך)

תמונה שתופסת חצי מרוחב המסך, וטקסט ברוחב מוגבל

כדי ליצור עיצוב כזה מגדירים כך:

טבלה / עיצוב / שוליים / שוליים פנימיים = 0 מימין ומשמאל (כדי שהטבלה תגיע לקצה של המסך)

טבלה / עיצוב / יישור תאים / יישור אנכי = מרכז (כדי שכל התכנים יהיו ממרוכזים)

תמונה / עריכה / רוחב = רוחב מלא (כדי שכל תמונה תתפוס את הרוחב המלא של התא שבתוכה היא נמצאת, במקרה שלנו זה מוביל לחצי מרוחב המסך)

מוסיפים לתא השמאלי אלמנט קבוצה, שמים בתוכו אלמנטי טקסטים

קבוצה / עיצוב / סגנון קבוצה = קבוצה שקופה ללא עיצוב (אנחנו רוצים שהקבוצה תהיה שקופה, ונהנה מהיכולת שלה להגביל את הרוחב של התוכן)

קבוצה / עיצוב / רוחב = רוחב מקסימלי לטקסטים

קבוצה / עיצוב / רוחב / יישור אופקי = ימינה (כדי שהטקסט יהיה צמוד לימין)

קבוצה / עיצוב / שוליים / שוליים פנימיים = 0 למעלה ולמטה (אנחנו לא רוצים שהקבוצה תוסיף גובה לתא)

טקסט ראשון / עיצוב / שוליים = מרחק מלמעלה = 0 (אנחנו לא רוצים שהטקסט יוסיף גובה לתא)

טקסט אחרון / עיצוב / שוליים = מרחק מלמטה = 0 (אנחנו לא רוצים שהטקסט יוסיף גובה לתא)

ההגדרות הן כמו בסעיף הקודם, עם השינויים האלה:

טבלה / עריכה / כיוון עמודות = משמאל לימין (מאוד חשוב, אחרת בנייד התמונה תופיע מתחת לטקסטים, ולא להיפך)
