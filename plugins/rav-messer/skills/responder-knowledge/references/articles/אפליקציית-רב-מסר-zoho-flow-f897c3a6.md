# אפליקציית רב מסר – zoho flow

Category: תוספים של רב מסר

Zoho Flow היא פלטפורמת אינטגרציה (iPaaS) המאפשרת לחבר בין מערכות שונות וליצור תהליכי עבודה אוטומטיים (Flows) ללא צורך בכתיבת קוד. התהליך מבוסס על שני מרכיבים עיקריים:

Trigger (טריגר/הדק): אירוע שקורה במערכת אחת (למשל: נמען חדש התווסף לרשימה ברב מסר).

Action (פעולה): מה קורה בעקבות הטריגר במערכת אחרת (למשל: יצירת ליד ב-CRM או שליחת הודעה ב-WhatsApp).

שלב 1: הכנת מפתח ה-API ברב מסר

כדי ש-Zoho Flow יוכל 'לדבר' עם החשבון שלכם ברב מסר, עליכם להפיק טוקן (User Token).

היכנסו לחשבון רב מסר שלכם.

עברו ל-הגדרות > חיבורים חיצוניים (API).

חפשו את הטוקן שנקרא Zoho Flow. לחצו לצפיה בטוקן והעתיקו אותו בלחיצה בכפתור ההעתקה.

שלב 2: יצירת חיבור חדש ב-Zoho Flow

לאחר שיש לכם את הטוקן, נעבור לממשק של Zoho Flow:

בתוך Zoho Flow, עברו ללשונית Settings > Connections.

לחצו על Create Connection ובחרו באפליקציית Responder (רב מסר).

בחלון שייפתח:

Connection Name: תנו שם ברור, למשל: Responder\_Production\_Account.בחלון ההגדרות:

User Token: הדביקו את הקוד שהעתקתם מרב מסר.

לחצו על Authorize. בסיום, תקבלו הודעה שהחיבור תקין: 'Connection is working fine'.

שלב 3: הגדרת טריגרים (Triggers)

כעת תוכלו לבחור איזה אירוע ברב מסר יפעיל את האוטומציה. בעת הגדרת הטריגר, תוכלו לבחור מבין האפשרויות הבאות:

1 - When a new subscriber is added: כשנרשם חדש מצטרף לרשימה.

2 - When an existing subscriber is updated: כשפרטי נרשם קיים מתעדכנים.

5 - When an existing subscriber resubscribe to the list: כשנרשם חוזר לרשימה אחרי שהיה בהסרה.

טיפ: ניתן לבחור מספר אירועים בו-זמנית על ידי שימוש באפשרות 'Use a Custom Value' והזנת המספרים מופרדים בפסיקים (למשל: 1,2,5).

שלב 4: סינון נתונים (Filtering) בשלב הטריגר

לפעמים תרצו שהאוטומציה תפעל רק בתנאים מסוימים. Zoho Flow מאפשר לכם להוסיף Filter criteria. ניתן לסנן לפי:

שם הרשימה (List name).

תגיות (Tags).

שדות מותאמים אישית (שם פרטי, טלפון וכולי).

סטטוס הנמען.

ותק הנמען.

תאריך כניסה של הנמען לרשימה.

שלב 5: פעולות זמינות (Actions)

לאחר שהגדרתם את הטריגר, תוכלו לבצע מגוון פעולות ברב מסר (כאשר רב מסר היא האפליקציה שמקבלת את המידע):

Create List: יצירת רשימה חדשה.

Create subscriber: יצירת נמען חדש.

Fetch subscriber: שליפת פרטי נרשם כדי להשתמש בהם בהמשך ה-Flow.

Remove Subscriber from list: הסרת נמען מרשימה.

Remove Subscriber from an account: הסרת נמען מהחשבון.

Remove tag: הסרת תגית מנמען.

Update subscriber: עדכון פרטים של נמען קיים.

Unsubscribe Subscriber Status: עדכון סטטוס של נמען בחשבון.

טיפים לעבודה נכונה

בדיקה (Test): תמיד השתמשו בכפתור 'Test' ב-Zoho Flow לפני הפעלת התהליך (Switch On).

שמות שדות: ודאו שהשדות ברב מסר (כמו 'שם פרטי') תואמים לסוג הנתונים שאתם שולחים מהמערכת השנייה.

היסטוריית ריצה: אם משהו לא עבד, היכנסו ללשונית History ב-Zoho Flow. שם תוכלו לראות בדיוק איפה התהליך נעצר ומה הייתה הודעת השגיאה.
