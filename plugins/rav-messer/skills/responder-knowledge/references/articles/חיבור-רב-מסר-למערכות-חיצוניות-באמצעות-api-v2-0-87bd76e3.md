# חיבור רב מסר למערכות חיצוניות באמצעות API V2.0

Category: רב מסר ומערכות חיצוניות

רוצים לחבר מערכת חיצונית או כלי AI לרב מסר? ממשק ה-API שלנו מאפשר למערכות שלכם – כגון אתרי מסחר, מערכות CRM, מנועי אוטומציה או מודלי בינה מלאכותית (כמו Claude) – לתקשר בצורה ישירה ומאובטחת עם החשבון שלכם. החיבור מאפשר להריץ מגוון פעולות אוטומטיות ללא מגע יד אדם: הוספת נמענים לרשימות תפוצה, עדכון שדות מותאמים אישית, ניהול תגיות ושליפת נתונים בזמן אמת.

בדקתם ואין אינטגרציה מובנית למערכת שלכם? בונים פיתוח ייעודי מאפס?


הנה התהליך שלב-אחר-שלב להפקת מפתחות ה-API והגדרת החיבור מול רב מסר:


כדי שהמערכת החיצונית תוכל לגשת לחשבון שלכם, עליכם להפיק אסימון משתמש ומפתחות גישה ייעודיים. פעולה זו מתבצעת פעם אחת מתוך ממשק המשתמש של רב מסר:

1. התחברו לחשבון שלכם במערכת רב מסר.
2. נווטו אל **הגדרות החשבון** על ידי לחיצה על סימלון גלגל השיניים (הגדרות) בפינה השמאלית עליונה של המסך
3. היכנסו ללשונית **"חיבורים חיצוניים (API)"**.
4. בראש הדף, אתרו את החיבור **"מפתח כללי לחשבון"**, העבירו אותו למצב **פעיל**, והעתיקו את הנתונים הבאים באמצעות כפתור ההעתקה:
  - **Client ID**
  - **Client Secret**
  - **User Token**

רב מסר משתמשת בפרוטוקול אימות מאובטח, לפיו יש להמיר את ה-User Token לאסימון גישה זמני (**Access Token**) המשמש לאישור הבקשות השונות במערכת.

כדי לקבל את ה-Access Token, עליכם לשלוח בקשת `POST` לשרת ההזדהות של רב מסר, יחד עם גוף הבקשה (Body) בפורמט JSON:

1. `{`
2.   `"grant_type": "client_credentials",`
3.   `"scope": "*",`
4.   `"client_id": 238,`
5.   `"client_secret": "YOUR_CLIENT_SECRET_HERE",`
6.   `"user_token": "YOUR_USER_TOKEN_HERE"`
7. `}`

לאחר שליחת בקשת ההזדהות, השרת יחזיר אובייקט JSON המכיל את אסימון הגישה (access\_token).

את הטוקן שתקבלו יש לצרף לכל בקשה עתידית שתשלחו ל-API (כגון יצירת נמען, עדכון תגית או שליפת רשימות). הצירוף מתבצע בתוך כותרות הבקשה (Headers) באופן הבא:

Authorization: Bearer YOUR\_ACCESS\_TOKEN



את רשימת הנתיבים (Endpoints) והפעולות האפשריות תוכלו למצוא בתיעוד ה-API הרשמי כאן.


לאחר ביצוע תהליך ההזדהות וקבלת ה-Access Token, ה-API פותח דלת למגוון אינטגרציות ואוטומציות ללא מגע יד אדם:

1. **סנכרון נתונים אוטומטי מול מערכות CRM**
  - ***התרחיש:*** מזינים ליד חדש ב-CRM או מעדכנים סטטוס לקוח (למשל: מ"מתעניין" ל"לקוח משלם").
  - **הפעולה ב-API:** המערכת החיצונית שולחת קריאה לרב מסר להוספת הנמען לרשימת "לקוחות פעילים", הסרתו מרשימת "מתעניינים", ועדכון שדות מותאמים אישית (Custom Fields) כגון תאריך רכישה או איש קשר מטפל.
2. **טריגרים ואוטומציות למסחר אלקטרוני (E-commerce)**
  - **התרחיש:** לקוח מוסיף מוצרים לעגלת הקניות אך נוטש לפני התשלום, או משלים רכישה בהצלחה.
  - ***הפעולה ב-API:*** אתר הסחר מעביר קריאה להוספת תגית (Tag) ספציפית לנמען (כגון: נטש-עגלה או רכש-קורס-דיגיטלי), שמפעילה באופן מיידי סדרת מסרים אוטומטית שנבנתה ברב מסר.
3. **ניהול הרשמות מאירועים ופלטפורמות וובינר**
  - ***התרחיש:*** משתמש נרשם להדרכה אינטרנטית דרך מערכת חיצונית או טופס עצמאי.
  - ***הפעולה ב-API:*** פלטפורמת האירועים משדרת את פרטי הנרשם ל-API. הנמען נוצר במערכת ומשויך מיידית לרשימת הדיוור של האירוע לקבלת תזכורות אוטומטיות.

חיבור API מיועד לבעלי רקע בפיתוח. במידה ואתם מחפשים דרך לחבר את המערכות ללא צורך בכתיבת קוד – שרת ה-MCP שלנו הוא הפתרון עבורכם.

1. **תוקף הטוקן:** ה-`access_token` שמתקבל הוא בעל תוקף זמני. בתכנון המערכת החיצונית שלכם, מומלץ להטמיע מנגנון המזהה שגיאות מסוג `401 Unauthorized` ומבצע בקשת הזדהות מחדש באופן אוטומטי.
2. **מבנה נתונים:** ודאו כי כל בקשות ה-`POST` או ה-`PUT` שנשלחות ל-API מוגדרות עם ה-Header:
Content-Type: application/json
