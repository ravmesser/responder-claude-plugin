# Landing Pages (דפי נחיתה)

Build, design, and publish landing pages with the visual editor. For connecting a
page to your own domain see `domains-deliverability.md`. For signup forms see `forms.md`.

## The editor (היכרות עם עורך דפי הנחיתה)
Pages are built from **elements** (headings, text, images, video, buttons). Start from
a **template** (matched to a goal: event, webinar, newsletter; mobile-adapted) or blank.
Workflow:
1. Pick a template by content type, or start blank.
2. Add & arrange elements on the canvas.
3. Customize content and styling.
4. **Groups (קבוצות):** bundle elements together with shared border/background/effects.
5. Adjust for mobile/responsive viewing.
- Article: [offline article catalog](articles/INDEX.md)

## Create a landing page with AI (יצירת דפי נחיתה באמצעות AI)
Three methods:
1. **Full page from external AI code:** generate HTML (and CSS/JS) in ChatGPT/Claude,
   paste into the **"קוד AI חיצוני" (External AI Code)** template fields (HTML required,
   CSS/JS optional). Embed a signup form via the sidebar **"הטמעת טופס"** (the system
   gives you a ready prompt telling the AI where to place the form). Preview & publish.
2. **AI code element on an existing page:** Add Elements (+) → **External AI Code
   Element** (Miscellaneous) → describe the component (e.g. pricing table) → copy the
   generated prompt → make the code in your AI tool → paste back.
3. **AI image:** add an image element → "create new image using external AI" → describe
   it → copy prompt → generate in DALL·E/Midjourney → upload.
- Article: [offline article](articles/יצירת-דפי-נחיתה-באמצעות-ai-12b0146b.md)
