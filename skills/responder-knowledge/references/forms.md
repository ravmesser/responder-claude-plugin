# Forms (טפסים)

**same editor** as landing pages and emails, so most form mechanics live alongside the
landing-page articles.

## Typical "create a form" flow
1. In the editor create/choose a form template (or add a form element to a page).
2. Add the fields you need (`הוספת שדות לטופס`).
3. **Connect the form to the target list** so signups are stored there
   (`חיבור רשימת נמענים לטופס הרשמה`) — create the list first via
   `lists-and-recipients.md` if it doesn't exist.
4. Optionally set a **thank-you page** and enable **double opt-in** on the list.
5. Publish the page/form, or embed it (WordPress plugin / HTML embed).
