# איך להטמיע טופס באתר שלכם

Category: דפי נחיתה

לאחר שסיימתם לעצב את טופס ההרשמה שלכם ברב-מסר, השלב הבא הוא להטמיע אותו באתר כדי להתחיל לאסוף לידים. מעבר לאפשרות הסטנדרטית של הטמעה באתרים ודפי נחיתה, הוספנו יכולות חדשות המאפשרות לכם להטמיע את הטפסים בקלות גם בכלי בנייה מבוססי AI כמו Lovable ו-Base44.

כדי להתחיל, לחצו על כפתור 'פרסום' בתוך עורך הטפסים.

בחלון שייפתח ('הטופס פורסם'), תוכלו לבחור את סוג קוד ההטמעה מתוך התפריט

קוד הטמעה לאתרים/דפי נחיתה סטנדרטיים

זוהי הדרך המסורתית להטמעת טפסים. המערכת מייצרת קוד JavaScript קצר שניתן להדביק בתוך עורך ה-HTML של האתר שלכם (וורדפרס, וויקס, או כל מערכת אחרת). הטופס יופיע כחלק בלתי נפרד מהדף במיקום שבו הדבקתם את הקוד.

מעתיקים את קוד ההטמעה ומדביקים אותו בדף שבאתר שלכם. אם אתם עורכים ישירות ב-HTML פשוט הדביקו את הקוד במקום הרצוי. אם אתם משתמשים בפלטפורמה דוגמת Wix, מוסיפים אלמנט 'קוד' או 'Embed' שמאפשר הכנסת קוד HTML ישירה ומדביקים את הקוד שם.

ההטמעה מתבצעת ב-JavaScript כדי לשמור את הקשר בין הטופס המוטמע לעיצוב הטופס ברב מסר, כך שכל שינוי שתעשו כאן יעודכן מיידית באתר שלכם. זו גם הטמעה קלה יותר כי היא מייצרת למעשה שורת HTML בודדת אותה תכניסו אל האתר שלכם.

פרומפט הטמעה למערכת Lovable

עבור משתמשים הבונים את האתר שלהם באמצעות פלטפורמת ה-AI של Lovable, המערכת מייצרת פרומפט מוכן לשימוש. בבחירה באפשרות זו, תקבלו הנחיה באנגלית הכוללת את קוד ההטמעה עם הפרמטר הייעודי __loveable__=true.

כל שעליכם לעשות הוא להעתיק את הפרומפט ולהדביקו בצ'אט של Lovable. המערכת תזהה את הקוד ותדע למקם את הטופס כאלמנט HTML מובנה (inline) בתוך האפליקציה או האתר שאתם בונים, תוך שמירה על תאימות מלאה.

אם אתם עובדים עם מערכת Base44, תוכלו לבחור באפשרות 'פרומפט הטמעה למערכת Base44'.

המערכת תפיק עבורכם פרומפט ייעודי הכולל קוד עם הפרמטר __base44__=true.

העתקת הפרומפט הזה לתוך ממשק העריכה של Base44 תנחה את ה-AI להטמיע את טופס ההרשמה בצורה אופטימלית כאלמנט HTML חי. שיטה זו חוסכת לכם את הצורך בהגדרות טכניות מורכבות ומבטיחה שהטופס יוצג ויפעל כראוי בתוך הסביבה של Base44.

טיפ: בכל אחת מהאפשרויות, תוכלו ללחוץ על 'הצגת קוד/פרומפט ההטמעה' כדי לראות את התוכן לפני ההעתקה, או על 'העתקת קוד/פרומפט ההטמעה' כדי להעבירו ישירות ללוח (Clipboard) שלכם.
